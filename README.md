# Social media content hosting

Temporary hosting for media published to the user's social pages (Wate / වටේ, E Positive, and others).

- Upload media here, then use the raw URL when scheduling in Buffer or Metricool:
  `https://raw.githubusercontent.com/wate-page/wate/main/<folder>/<file>`
- Delete a file once the post has been published to Facebook / YouTube.

Folders:
- `wate/` — වටේ reels and post images
- `epositive/` — E Positive reels, quote cards and the build pipeline (see `epositive/pipeline/RUNBOOK.md`)
